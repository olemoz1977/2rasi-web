# 2rasi web v0.1

First homepage experience prototype for 2rasi.com.

## UX principle
Familiar → Unexpected → Meaning.

## v0.1 scope
- Calm water / mist visual language
- Interactive lens: SEE → NOTICE
- Three experiment slots
- ConflictLab live prototype link
- Minimal About and contact
- Responsive/mobile-first behavior
- Reduced-motion accessibility
- Basic SEO/Open Graph metadata

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Deployment direction
Use a clean `2rasi-web` repository. Keep this presentation layer separate from future experiment backends, auth, payments, research data and user data.
