# PrioLens open impulse spectrum seed v0.1

Status: ACTIVE DISCOVERY SEED / NOT FINAL TAXONOMY
Date: 2026-08-31
Source: existing Gallery first-impulse audit and 40-image KEEP/HOLD curation.

## Purpose

Seed the broader impulse space from images already in Gallery rather than deriving a taxonomy only from theory.

This is not a scoring model. It is a discovery map for the next curation pass.

## Families already visible in the existing Gallery audit

### Self-direction / choice
Examples:
- `S05.webp` — choose the fitting tool.
- choosing a seat / direction / option in several historical scenes.

Working pull:
> I choose / I decide / I set this for myself.

### Discovery / curiosity / exploration
Examples:
- `S09.webp` — open and discover what is inside.
- `20260809_235839567.png` — look behind an obstacle / discover.
- `S01.webp` — move forward into an unseen route.

Working pull:
> I want to see what is there / go into the unknown.

### Mastery / precision / competence
Examples:
- `S12.webp` — precise measurement.
- `S16.webp` — skilled shaping.
- `1788135386167.png` — precise adjustment / assembly.

Working pull:
> I want to do this well / precisely / skillfully.

### Connection / reciprocity / belonging
Examples:
- `S03.webp` — connect with another person.
- `20260829_235204397.png` — act together / pass an object.
- group / pair / shared-warmth scenes in HOLD.

Potential future split:
- dyadic connection / reciprocity;
- belonging / being together.

Do not assume these are one family.

### Wider-system impact / influence
Examples:
- irrigation gate distributing water across a broader system;
- local switch changing the state of a wider room;
- domino / cascading reaction as a weaker variant.

Working pull:
> My local action changes something beyond the immediate object.

### Safety / protection / securing
Examples:
- `S08.webp` — shielding from rain.
- gate lock / access security.
- protective case / enclosure.

Potential future split:
- protection from harm;
- securing / access control.

### Control / boundary / routing
This family was partly hidden inside historical INF/PRO/CER assignments.

Examples:
- `S04.webp` — route / control a flow.
- lock / restrict access scenes.
- gate / enclosure / boundary scenes.
- physical control / activation scenes in the full audit.

Working pull:
> I set the boundary / route / state / rule of what happens next.

This is a candidate `NEW-FAMILY`, not yet validated.

### Opportunity / accessible possibility
Examples:
- prepared useful materials.
- ripe harvest plus basket.
- blank canvas plus tools.

Working pull:
> Something valuable is available to use now.

Potential future split:
- resource opportunity;
- creative possibility;
- reward/acquisition.

### Reward / acquisition / immediate resource
Examples in KEEP/HOLD or old DROP:
- gift opening.
- prepared food.
- ripe harvest.
- access / key scenes.

Working pull:
> I can get / take / use something rewarding or useful.

This may overlap with Opportunity but should not be merged automatically.

### Order / clarity / organization
Examples:
- assigned places / orderly arrangement.
- visible organized storage.
- sorting / alignment scenes in the full audit.

Working pull:
> I want things arranged / clear / known.

This may be more coherent than the old broad CER label.

### Rest / comfort / basic restoration
Examples in the full audit:
- sit / rest.
- warmth / comfort.
- drink / refresh.
- safe resting space.

Working pull:
> I want relief / comfort / restoration.

This family was largely outside the previous direction model and is important for basic-need coverage.

### Knowledge / learning / understanding
Examples in the full audit:
- learning / classroom.
- looking for knowledge / access to information.
- reading / seeing more clearly.

Working pull:
> I want to know / understand / learn.

Do not automatically equate this with certainty or exploration.

### Immersion / focus / engagement
Examples in the full audit:
- focused work.
- concentrated writing.
- deep engagement with a task.

Current evidence is weak because many scenes may simply depict work. Keep as a candidate gap/family to inspect visually.

## Families not yet clearly represented by the current 40-image compact bank

The following are theoretically plausible and appear underrepresented or absent in the current compact curation:
- care / caregiving / sacrifice for another;
- recognition / status / esteem;
- achievement / success / winning;
- authenticity / self-expression;
- justice / fairness;
- purpose / meaning;
- contribution / service.

Absence from the current compact bank does **not** mean absence from the 223-image Gallery. These are targeted re-open questions for historical DROPs before any new generation.

## Key structural consequence

The current evidence suggests that several old directions may contain multiple different pulls:

- `CON` may split into connection / belonging / care;
- `PRO` may split into protection / security / boundary control;
- `INF` may split into wider-system impact / control;
- `OPP` may split into opportunity / reward / creative possibility;
- `CER` may be better reframed around order / clarity / knowledge rather than forced as one certainty construct;
- `MAS` should be kept distinct from achievement/success until evidence supports merging.

## Next curation move

1. Start with the existing 40 KEEP/HOLD images.
2. Assign one or more **descriptive candidate pulls** without forcing old labels.
3. Re-open selected historical DROPs specifically for the missing families listed above.
4. Prefer vivid, immediately readable images over sterile theoretical purity.
5. Use `NEW-FAMILY` freely when the first impulse does not fit the seed.
6. Do not generate new images until the existing Gallery has been checked for these gaps.

The output should be a compact spectrum with representative live images, not a final psychological taxonomy.
