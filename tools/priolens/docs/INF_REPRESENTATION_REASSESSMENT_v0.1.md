# INF representation reassessment v0.1

Status: DESIGN REASSESSMENT / GATE D1 NOT PASSED
Date: 2026-08-31

## Why this document exists

Gate D1 asked whether INF preserves one coherent higher-level meaning across materially different opponents and scene mechanisms.

Working INF definition:

> meaningful impact on the direction, decision or outcome of an external/shared situation.

The current answer is **not enough evidence to pass**.

Two edges support a coherent INF-like core:
- R01 · CON↔INF
- R03 · AUT↔INF

But repeated attempts to establish a third materially different opponent failed for different reasons:
- MAS↔INF: skill/complexity confound, then construct dilution, then generic skill vs routing;
- PRO↔INF: zero-sum allocation introduced fairness/deprivation/valence;
- CER↔INF: clean `look vs steer` contrast, but INF collapsed to generic routing/control and CER to inspection/reveal.

## Structural diagnosis

The repeated problem is not merely bad stimulus writing.

`Influence` contains two semantic requirements:
1. **visible causal intervention**: the actor changes something beyond their own local action;
2. **meaningful shared/external consequence**: the change matters to a wider situation, not merely to an internal mechanism.

Static matched scenes can usually show requirement 1.

Requirement 2 is difficult to show without introducing one or more extra signals:
- another affected person/group → social salience, leadership/status, fairness;
- visibly better/worse outcome → valence/reward/loss;
- more objects/greater spread → magnitude/salience;
- scarce shared resource → zero-sum allocation/fairness;
- complex system → technical competence/Mastery;
- unstated downstream importance → hidden story.

Therefore the current visual proxy `redirection / steering` is observable, but it is **not equivalent to Influence** as currently defined.

## What the evidence does support

The reviews repeatedly recover a narrower observable family:

> **external steering / redirection**: an actor changes the course, routing or allocation of something beyond the actor's own local task.

This is a scene-property family, not yet a psychological direction.

Do not silently rename this proxy `Influence` and treat the problem as solved.

## Strategic options

### Option A · Narrow INF to observable steering
Redefine the working direction toward `Steering / Directional Impact`.

Pros:
- directly visualizable;
- cross-edge mechanism is relatively stable;
- fewer hidden-story requirements.

Cons:
- materially changes the intended psychological meaning;
- risks measuring attraction to control/mechanical causality rather than a broader priority;
- would require restarting semantic validation under the new definition.

### Option B · Keep current INF, but require richer shared consequence
Preserve current definition and use scenes where the wider consequence is genuinely visible.

Pros:
- preserves intended meaning.

Cons:
- current static-image discipline repeatedly introduces social, valence, magnitude or fairness confounds;
- likely requires dynamic/multi-frame stimuli or a different modality rather than another edge-specific static-image repair.

### Option C · Hold INF from public scoring
Keep INF as a research hypothesis but do not require it in the first public direction set.

Pros:
- respects current evidence;
- avoids forcing exactly eight scores;
- allows PrioLens architecture to be tested using more visually tractable directions.

Cons:
- temporarily loses a conceptually important direction.

## Recommendation

Adopt **Option C now**.

Do not redefine INF merely to rescue the current static-image architecture. Mark it:

> `INF status: HOLD / PARTIAL_IDENTITY / NOT PUBLIC-SCORE READY`

Preserve R01 and R03 as useful evidence, but do not render them as a three-edge INF validation set yet.

The next architecture question should be:

> Can a more visually tractable direction preserve coherent identity across multiple opponents under the same matched-edge discipline?

Use **MAS · Mastery** as the next falsification target because the operationalizability audit rates MAS highest for static images. This is deliberately an easier test.

Interpretation:
- if MAS also fails cross-edge identity, the problem may be architecture-wide;
- if MAS succeeds while INF remains partial, the architecture may work selectively and the public set should include only directions that survive.

## Next gate proposal

Open **Gate D2 · MAS cross-edge identity**.

Constraints:
- do not use INF as one of the first MAS opponents because MAS↔INF has already been exhausted;
- choose at least three materially different opponents/mechanisms;
- require blind semantic recurrence of `quality/skill/competence of execution` across those edges;
- reject a result explainable mainly by `hands/craft/tools/technical difficulty`;
- no rendering until text-level blind + reveal review survives.

This is a project-level architecture test, not validation of MAS as a trait.
