## Important historical contradictions found

### 1. Old target was 3 exemplars; current target is 2

Several early audit boards in the chat explicitly targeted:

- 3x INF
- 3x MAS
- 3x OPP

That target is obsolete.

Current protocol architecture requires **2 conceptually independent exemplars per each of 8 directions = 16 active stimuli**.

Do not use old `3x` audit-board counts to reconstruct current state.

### 2. Acronym `INF` was used for two different meanings

Early generation boards used the label:

`INFORMATION CLARITY (INF)`

Current frozen PrioLens direction codes are:

- `INF` = Influence / Poveikio siekis
- `CER` = Certainty / Aiškumo poreikis

Therefore early `INF` labels on question/document/fog/map concepts are **obsolete labels** and must never be interpreted as current Influence mappings.

Map those concepts only by current semantic definitions, not by their old board headers.
