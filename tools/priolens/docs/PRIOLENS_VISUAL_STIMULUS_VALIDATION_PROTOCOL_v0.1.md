## Purpose

This tool validates/selects **visual stimuli**, not people and not the PrioLens construct model.

Primary question:

> Does a specific image communicate its intended visual mechanism clearly enough, without a stronger neighboring interpretation?

Do **not** infer from this study that:
- a visual family is a basic human need;
- attraction to an image means an unmet need;
- a response time is psychological strength;
- passing this screen establishes construct validity.

The current Open14 v0.4 public pilot remains analytically separate and its active 42-image bank is not mutated by this study.

## Assignment design

Each participant rates **12 of the 42** images.

Seven predefined deterministic forms are generated by rule:
- every form contains 12 different families;
- no form contains two exemplars from the same family;
- each family is absent from exactly one of the seven forms;
- each of the 42 exemplars appears in exactly two forms;
- therefore all 42 exemplars receive equal planned exposure across a balanced seven-form cycle.

The participant's form is assigned from the anonymous session UUID. Presentation order is randomized deterministically within the assigned form.

Owner/test mode may override the form with `?form=0..6` for QA only.

## Blind sequence per stimulus

### Step 1 — open semantic read

The image is shown **without family labels or mechanism options**.

Participant answers:
1. brief open description: what is most important / what is happening / what the image communicates;
2. clarity rating 1–5: how clearly the image communicates one main idea.

The open description is collected before any PrioLens mechanism wording is shown.

### Step 2 — closed discriminant choice

The same image remains visible.

Participant chooses one description from:
- the intended mechanism;
- three pre-specified nearest competing mechanisms;
- `OTHER / none of these`.

Option order is randomized deterministically per session × stimulus.

Participant then rates:
- confidence in the classification, 1–5;
- overall emotional tone / valence, 1–5.

No answer is marked correct or incorrect.

## Pre-set screening decision rule

No KEEP/REVIEW/REPLACE decision before:

> **n ≥ 40 independent ratings for the specific stimulus**

### KEEP candidate

All must hold:
- intended classification rate ≥ 60%;
- strongest neighboring competitor ≤ 20%;
- OTHER ≤ 20%;
- mean clarity ≥ 3.5 / 5;
- mean confidence ≥ 3.5 / 5.

### REPLACE candidate

Any of:
- intended classification rate < 40%;
- strongest neighboring competitor ≥ 35%;
- OTHER ≥ 35%;
- strongest neighboring competitor rate ≥ intended classification rate.

### REVIEW

All cases between KEEP and REPLACE.

### COLLECTING

n < 40.

These thresholds are pragmatic **screening/selection rules**, not proof of psychometric validity.

## Bilingual analysis

The owner summary exposes:
- ALL;
- LT;
- EN.

Do not pool LT and EN blindly. A stimulus that passes overall but shows materially different LT/EN semantic classification should remain REVIEW until the language effect is understood.

## What this tool does not yet solve

This v0.1 tool does not by itself estimate or control:
- face count / human-presence bias;
- luminance/contrast;
- saturation;
- visual complexity from image features;
- novelty/unusualness;
- food/wealth/status cues;
- behavioral MOST/LEAST coherence in the main PrioLens pilot.

Those are separate nuisance/behavioral layers.

Valence is collected here because it is cheap and directly useful as one nuisance signal.

## Next analytical gate

After adequate ratings per stimulus:

1. apply the pre-set semantic/discriminant screen;
2. inspect LT/EN separately;
3. inspect open-text coding independently from the closed-choice rate;
4. combine with main-pilot exemplar/slot/opponent effects;
5. only then decide KEEP / challenger-needed / replace for a future bank version.

Do not mutate the active public-pilot bank mid-cohort.
