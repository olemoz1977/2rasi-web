# PrioLens need-state and impulse-priority architecture v0.1

Status: ACTIVE RESEARCH HYPOTHESIS / NOT VALIDATED MODEL
Date: 2026-08-31

## Why this exists

The current seven/eight PrioLens directions are not assumed to be exhaustive. Recent review exposed a likely category-space problem: some meaningful impulses such as caring, recognition, success, authenticity, justice, purpose or control/assertion may not fit cleanly inside AUT / EXP / MAS / CON / INF / PRO / OPP.

AgileBrain is useful here as an external comparison because it separates twelve emotional-need categories across self, material, social and spiritual domains. It is not adopted as the PrioLens model and its stronger interpretation `strong response = unmet need` is not imported.

Maslow-style layers are used only as a coarse coverage map. PrioLens does not assume a strict hierarchy or that a person occupies one single need level.

## Core architecture hypothesis

PrioLens should separate two different observations:

1. **revealed visual priority** — what repeatedly wins in low-deliberation visual choice;
2. **perceived sufficiency** — how sufficiently the person feels broader life-need domains are currently met.

These two layers are compared, not collapsed into one psychological score.

## Order of measurement

To reduce priming, the current preferred order is:

### Part A — visual priority first

The participant makes fast visual choices without seeing need labels or first rating what is lacking.

Capture:
- chosen stimulus;
- competing stimuli;
- exemplar identity;
- position / sequence;
- `no_clear_choice`;
- latency as UX/process telemetry only.

The output is session-level choice tendency, not a trait or diagnosis.

### Part B — perceived sufficiency second

After the visual task, ask the participant how sufficiently broader need domains are currently represented in their life.

Do **not** ask for one global Maslow stage. A person can be secure in one domain and deprived in another.

Candidate macro domains for research coverage:
- basic resources / physical comfort;
- safety / stability / predictability;
- connection / belonging / care;
- agency / esteem / recognition;
- growth / mastery / exploration / authenticity;
- meaning / contribution / justice / purpose.

Exact wording and number of domains are not frozen.

## Comparison layer

The interesting object is the relation between the two layers.

Examples:

| Perceived sufficiency | Visual priority | Research reading |
| --- | --- | --- |
| low | high | currently salient / active candidate domain |
| high | high | may be intrinsically valued, not merely lacking |
| low | low | ambiguous: avoidance, fatigue, competing priorities, weak stimuli or other explanation |
| high | low | possibly settled / currently less salient |

These are hypotheses for reflection, not diagnostic labels.

## Candidate impulse universe

Do not freeze the current seven directions as the only possible spectrum.

Use theory only as a **coverage and omission check**, not as a ready-made scoring taxonomy.

Current broad candidate space includes, without claiming exhaustiveness:
- safety / protection;
- care / caregiving;
- connection / belonging / inclusion;
- autonomy / self-direction;
- control / assertion;
- recognition / status;
- mastery / competence;
- achievement / success;
- exploration / novelty;
- opportunity / reward;
- certainty / order;
- authenticity;
- justice / fairness;
- purpose / meaning;
- immersion / engagement;
- contribution / service.

Candidate families may later merge, split, disappear or be renamed.

## Theory boundary

Useful sources can include:
- Maslow-style need layers as macro coverage;
- Self-Determination Theory;
- Schwartz values;
- McClelland motives;
- approach / avoidance and promotion / prevention frameworks;
- caregiving, attachment, exploration, threat-defense and dominance/control literature;
- AgileBrain as a neighboring applied visual-need framework.

But PrioLens must not claim direct neural-system measurement, latent-need diagnosis, subconscious truth or a scientifically complete taxonomy merely because a candidate family resembles one of these theories.

## Gallery implication

The Gallery should no longer be treated only as an asset bank for the existing seven directions.

Active open-coding rule:

> **image → first spontaneous pull / meaning → candidate impulse family → KEEP / HOLD / DROP / REASSIGN / NEW-FAMILY**

Questions during curation:
1. What does a normal viewer get from the image in about one second?
2. Is the image alive / engaging enough to create a real choice?
3. What impulse does it most naturally invite?
4. Is that impulse already represented, or does it suggest a missing family?
5. Is a competing interpretation genuinely stronger, or merely possible?

Do not optimize toward semantic sterility. Emotion is not a confound by itself. The risk is systematic salience imbalance across families.

## Product guardrail

The public result should not say:
- `this is your unmet need`;
- `this is your Maslow level`;
- `this is your subconscious priority`;
- `this is your true self`.

Safer product-level language remains descriptive:

> **What pulled you in this session, and how does that compare with what currently feels sufficiently present in your life?**
