# PrioLens open impulse spectrum gap audit v0.1

Status: ACTIVE DISCOVERY CHECK / NOT FINAL TAXONOMY
Date: 2026-08-31

## Basis

This pass reuses the completed 223-image Gallery first-impulse audit. It does **not** restart image coding from scratch.

The question is no longer `which of the old seven/eight directions fits this image?`

The question is:

> Which candidate impulses already have naturally readable visual material in Gallery, and which important families are absent or only reachable by post-hoc interpretation?

Important limitation: Gallery was historically generated around earlier ConflictLab / PrioLens questions. Therefore absence from Gallery is **not evidence that a human impulse is absent or inherently unvisualizable**. It may simply reflect generation-history bias.

## Families with clear existing visual footing

### REST / COMFORT / RESTORATION

Existing first impulses include:
- sit / rest;
- warmth / comfort;
- drink / refresh;
- rest / feel safe.

Conclusion: **SUPPORTED AS DISCOVERY FAMILY**.

This is important because earlier PrioLens direction sets largely omitted basic bodily/restorative pulls.

### SAFETY / PROTECTION

Existing material includes shielding from rain, locking / securing access, protective cases and robust enclosure.

Conclusion: **SUPPORTED AS DISCOVERY FAMILY**.

Potential later split remains protection-from-harm vs securing/access-control.

### CONTROL / ASSERTION / BOUNDARY

Existing material includes:
- routing / controlling a flow (`S04` and related variants);
- switching or changing a wider environment state;
- locking / restricting access;
- physical settings / activation;
- gates, boundaries and enclosure.

Conclusion: **SUPPORTED AS `NEW-FAMILY` CANDIDATE**.

This family was previously distributed across INF / PRO / CER. The visual bank suggests a coherent concrete pull around setting what happens next, controlling flow/state or establishing a boundary.

Do not equate this automatically with dominance, power or Karpman Persecutor.

### ORDER / CLARITY / ORGANIZATION

Existing first impulses include assigned places, orderly arrangement, visible storage, sorting, grouping and alignment.

Conclusion: **SUPPORTED AS DISCOVERY FAMILY**.

This appears more visually concrete than the old broad CER / certainty construct.

### KNOWLEDGE / LEARNING / UNDERSTANDING

Existing first impulses include classroom/learning, access to knowledge, reading, seeing more clearly and searching for an answer.

Conclusion: **SUPPORTED AS DISCOVERY FAMILY**.

Do not collapse automatically into exploration or certainty.

### REWARD / RESOURCE / ACQUISITION

Existing first impulses include prepared food, gift opening, ripe harvest, key/access and immediately usable resources.

Conclusion: **SUPPORTED AS DISCOVERY FAMILY**, with obvious salience/reward confounds to track rather than sterilize away.

### EXPLORATION / DISCOVERY

Existing material is broad enough: reveal, peek/curiosity, unseen path, uncertain direction.

Conclusion: **SUPPORTED AS DISCOVERY FAMILY**.

### MASTERY / PRECISION / COMPETENCE

Existing material is strong: exact measurement, skilled shaping, precise adjustment and fit.

Conclusion: **SUPPORTED AS DISCOVERY FAMILY**.

### CONNECTION / RECIPROCITY / TOGETHERNESS

Existing material includes dyadic connection, passing/handling an object together, pair/group scenes and shared warmth.

Conclusion: **SUPPORTED, BUT LIKELY TOO BROAD AS ONE FAMILY**.

The bank already suggests at least a distinction between:
- dyadic reciprocity/contact;
- belonging/togetherness.

## Families that Gallery does NOT currently support cleanly

### CARE / CAREGIVING / SACRIFICE FOR ANOTHER

Closest existing scenes:
- `20260731_043300801.png` — sharing warmth / being together;
- `20260730_230816104.png` — sharing a drink / being a pair;
- `20260829_235204397.png` — acting together / passing an object;
- `20260730_234851456.png` — two-person closeness / being together.

Problem: their recorded first impulses are connection, reciprocity or togetherness. None clearly reads as **I take care of the other / I give up something for the other's welfare**.

Conclusion: **REAL GAP IN CURRENT GALLERY**.

Do not relabel connection scenes as CARE merely to fill the family.

### RECOGNITION / STATUS / ESTEEM

Closest historical scenes are group interaction, formal meeting space and face-to-face contact.

Problem: no Gallery first-impulse record directly says acknowledgement, praise, admiration, being seen for one's contribution, rank or esteem.

Conclusion: **REAL GAP IN CURRENT GALLERY**.

Do not infer recognition from the mere presence of an audience or group.

### ACHIEVEMENT / SUCCESS / WINNING

Closest existing material:
- `20260730_063306116.png` — finish / mark done;
- `20260830_242641908.png` — complete a missing part;
- `file_00000000fb088246a218b6e0c6f2e60e.png` — finish a puzzle;
- `1785953971401.png` — grow / become stronger.

Problem: these primarily read as completion, problem-solving or growth, not success/achievement relative to a goal, standard or competitor.

Conclusion: **WEAK / PARTIAL FOOTING**.

Completion may later prove to be one visual family of achievement, but it should not be assumed.

### AUTHENTICITY / SELF-EXPRESSION

Closest existing material:
- preparing/dressing;
- choosing/checking glasses;
- choosing among variants;
- blank canvas / creative possibility.

Problem: these read as preparation, choice, style selection or creativity. None directly reads as **expressing who I am / resisting conformity / being recognizably myself**.

Conclusion: **REAL GAP IN CURRENT GALLERY**.

### JUSTICE / FAIRNESS

Closest existing scenes are order, assigned places, separation/grouping and strategy.

Problem: order is not fairness. Equal spacing is not justice. Strategy is not justice.

Conclusion: **REAL GAP IN CURRENT GALLERY**.

Do not use geometric balance or symmetry as a semantic shortcut for fairness unless people actually read it that way.

### PURPOSE / MEANING

Closest existing material is growth potential, greenhouse/growth and forward-route imagery.

Problem: growth, opportunity and direction are not meaning/purpose. The purpose relation requires something about why an action/life direction matters, which the current static scenes do not carry directly.

Conclusion: **REAL GAP IN CURRENT GALLERY**.

This may be intrinsically harder to represent with a single static scene, but current Gallery cannot answer that question because it was not built to try.

### CONTRIBUTION / SERVICE

Closest existing material:
- repairing/restoring (`20260731_042747442.png`);
- irrigation/wider-system benefit;
- reciprocal joint work.

Problem: useful action or system effect is visible, but **benefit to others / contribution beyond self** is not consistently the first read.

Conclusion: **WEAK / PARTIAL FOOTING**.

## Structural finding

The existing Gallery is much richer in **concrete action/state impulses** than in abstract social/aspirational impulses.

Strong visual territory already present:
- rest/comfort;
- safety/protection;
- control/boundary;
- order/clarity;
- knowledge/learning;
- reward/resource;
- exploration;
- mastery;
- connection.

Sparse territory:
- care;
- recognition/status;
- achievement/success as distinct from completion;
- authenticity;
- justice;
- purpose;
- contribution/service.

Do **not** interpret this asymmetry as evidence for a hierarchy of human importance. It is at least partly a historical asset-generation bias.

## Immediate consequence

Do not build the next P3 bank yet.

First build an **open impulse candidate map** with three statuses:

1. `VISUALLY_FOOTED` — Gallery already contains multiple plausible live exemplars;
2. `PARTIAL` — there is adjacent material but the intended pull is not yet the first read;
3. `GAP` — current Gallery does not provide a defensible exemplar.

Only after the candidate map is visible should we decide which GAP families deserve new image generation and which may be inappropriate for a single static image.
