# MAS ↔ INF R02 redesign v0.1

Status: TEXT-ONLY REPAIR CANDIDATE / NOT VALIDATED
Date: 2026-08-30

## Why R02 must change

Claude Gate D1 classified original R02 as CROSS_LOAD. The problem was not only the adjective `low-skill`.

Original structural asymmetry:
- MAS used a tool-mediated fine-tolerance action with gauge/caliper-like instrumentation;
- INF used a single simple selector;
- therefore step-count, tool involvement and perceived deliberateness were unequal.

A wording cleanup would not repair that.

## Repair target

Preserve the semantic edge:
- MAS = precision / quality of one bounded outcome;
- INF = directional consequence in an external/shared system.

Remove non-target asymmetries:
- same apparatus;
- same handwheel/control family;
- same visible effort and hand involvement;
- similar object density and mechanical complexity;
- no expert-vs-novice cue;
- no gauge/caliper/tool prestige cue;
- no bigger/more/busier INF cue;
- no correct-vs-wrong destination cue;
- no labels, numbers or text.

## R02R · same handwheel, different consequence

### Shared scene

A neutral tabletop mechanical apparatus on an ordinary workshop bench. One central handwheel moves an internal sliding element. Two equal downstream paths are visible in the apparatus. One participant's two hands are shown in the same positions in both variants: one hand turning the handwheel, the other steadying the apparatus. Same camera, lighting, materials, amount of moving material/tokens, path count and object density.

The apparatus must look equally ordinary and mechanically plausible in both variants. Neither side should appear more advanced, safer, more expensive, more powerful or more complete.

### Variant A

Turning the handwheel moves one small central component within a narrow pair of fixed physical guides. The close clearance between the component and guides makes fine positional control visibly relevant. The downstream routing remains unchanged and both equal downstream paths stay in the same state. The visible consequence of the action is confined to the exact fit/alignment/position of this one bounded component.

Important:
- do not show a gauge, caliper, scale, target mark or text;
- do not show a dramatically perfect final state;
- the action should read as careful fine positioning, not as 'correct answer achieved'.

### Variant B

Turning the same-size handwheel moves a same-size central sliding diverter within the same apparatus. The same existing flow/material is redirected from one equal downstream path to the other. Total amount, speed, number of paths and destination attractiveness remain unchanged. The visible consequence is that the course of the external apparatus changes.

Important:
- the handwheel action should look just as deliberate and mechanically involved as Variant A;
- do not make the diverter larger, more dramatic or more complex;
- neither downstream destination should look better, fuller, more useful or more rewarding.

## Intended hidden mapping

Do not show during blind Stage 1.

- Variant A = MAS
- Variant B = INF

## Main residual risks

1. A may read as generic accuracy/fit rather than broader Mastery.
2. B may read as generic causality/routing rather than broader Influence.
3. The apparatus may need slightly different central internal geometry across variants, weakening pure pixel-level matching.
4. If A looks like a difficult technical task and B like a simple route switch, the redesign has failed even without evaluative wording.
5. If B's downstream change becomes more visually salient than A's fine movement, salience rather than meaning may dominate.

## Acceptance criterion before rendering

A fresh blind reviewer should be able to describe approximately:
- A: careful fine positioning / exact fit / precision of a bounded local result;
- B: same-degree deliberate control whose consequence changes the route/course of the external system;

without describing either side as obviously more skilled, more powerful, more useful, more complete or more complex.

Only then may R02R replace old R02 in the INF cross-edge set.
