# PrioLens stimulus generation briefs v0.1

Status: INTERNAL CANDIDATE-GENERATION CONTRACT / NOT A STIMULUS FREEZE
Date: 2026-08-29

## Purpose

Define controlled generation briefs for the three directions where the recovered historical library no longer provides a defensible path to two independent exemplars: INF, MAS and OPP.

This document does **not** authorize a final mapping. Generated images remain candidates until they pass direct visual review, nearest-neighbour semantic challenge and cross-set confound review.

The working direction definitions in `DIRECTION_DEFINITIONS_v0.1.md` remain authoritative. Do not relax those definitions to rescue a generated image.

## Why generation is now justified

The historical review has reached a semantic exhaustion point for these three directions:

- INF: mapped social/chess/figure material does not visibly establish impact on a shared or external outcome without hidden story, dominance/status cues or projection.
- MAS: laptop/notebook/chess/craft-object material does not by itself establish skilled execution, refinement or competence.
- OPP: doors, corridors, open routes and forked paths repeatedly collapse into AUT/EXP because an opening is visible but its future value is not.

The exact pixels of every historical reserve have not all been directly reviewed. However, the recovered source families and participant cue history do not contain a natural INF or MAS family, and provide only borderline OPP material. Continuing to force-map those assets would weaken the semantic contract.

## Generation strategy

Do **not** generate exactly two images per direction. That creates quota pressure and encourages keeping weak outputs.

Generate an initial pool of **three conceptually different scenes per weak direction**:

- 3 INF candidates
- 3 MAS candidates
- 3 OPP candidates
- 9 candidate scenes total

Target after audit: at least two independent passing exemplars per direction. If fewer than two pass, generate another wave only for the failed direction.

A style variation of the same scene does not count as an independent concept.

## Shared visual grammar

All generated candidates should follow the same baseline unless the direction requires otherwise:

- square 1:1 composition;
- photorealistic, neutral documentary still rather than cinematic advertising;
- no text, numbers, logos, UI, recognizable brands or symbols that explain the intended meaning;
- no luxury/status styling;
- no dramatic danger, injury, medical imagery or extreme emotional valence;
- avoid faces where the meaning can be conveyed through hands, objects and visible consequences;
- if people/hands are necessary, avoid making age, gender, ethnicity, clothing status or attractiveness the dominant cue;
- moderate neutral lighting and contrast;
- similar visual complexity and object count across the eventual 16-image set;
- central action/outcome should be legible at mobile size;
- no direction-specific color coding;
- no captions or hidden narrative required to understand the visible action.

The generation prompt should describe the scene, not name the psychological direction.

## Neutral candidate IDs

Generated files should use neutral IDs during blind review:

- `G01`, `G02`, `G03` — internal target INF
- `G04`, `G05`, `G06` — internal target MAS
- `G07`, `G08`, `G09` — internal target OPP

The public or blind-review file presented to reviewers must not expose INF/MAS/OPP in the filename or metadata.

## INF candidate briefs

Working priority: visibly shaping the direction, decision or outcome of a shared/external situation.

### G01 — shared-flow diverter

**Scene:** A neutral tabletop physical system has several identical tokens or channels moving toward different destinations. One human hand moves a simple central diverter; the visible consequence is that several downstream tokens/channels are redirected together.

**What must be visible:** one action changes a multi-element external outcome, not merely the actor's own route.

**Avoid:** fine technical tools, control-room aesthetics, authority clothing, warning colors, text labels.

**Nearest-neighbour challenge:**
- vs MAS: the scene must be about consequence on multiple outputs, not precision skill.
- vs AUT: the hand is not choosing its own path; it changes the system's shared outcome.

### G02 — shared-plan reconfiguration

**Scene:** A simple physical tabletop model contains several neutral paths or participant markers converging on a shared destination. A hand moves one central route/priority piece and the visible geometry changes the route for several markers at once.

**What must be visible:** external/shared direction changes because of one consequential intervention.

**Avoid:** meeting-room hierarchy, pointing at people, faces, leadership poses, chess pieces, written plans.

**Nearest-neighbour challenge:**
- vs CON: togetherness must not be the main meaning.
- vs MAS: puzzle-solving/cleverness must not dominate.
- reject if the shared consequence is not legible without a story.

### G03 — consequential contribution

**Scene:** A partially assembled neutral system has several branches currently inactive. One hand places a single plain connector/component; immediately several branches visibly become connected/operational as one system.

**What must be visible:** the contribution changes what the larger system can do, beyond the person's private task.

**Avoid:** electronics branding, glowing sci-fi effects, complicated engineering detail, achievement symbolism.

**Nearest-neighbour challenge:**
- vs MAS: assembly skill must be secondary to the visible system-level effect.
- if the scene reads mainly as craftsmanship or repair, reject for INF.

**INF acceptance warning:** a social scene alone is never enough. If an independent viewer needs the sentence “this person is leading/influencing the others,” the candidate fails.

## MAS candidate briefs

Working priority: developing or applying competence, precision, skill or quality.

### G04 — precision fit

**Scene:** Two hands measure a plain mechanical or wooden component with a simple caliper, then align it precisely with a matching part. The fit/tolerance is visually clear.

**What must be visible:** deliberate measurement and refinement toward accurate fit.

**Avoid:** factory branding, performance dashboards, complex machinery, luxury craft object.

**Nearest-neighbour challenge:**
- vs INF: no wider shared outcome is being directed.
- vs CER: the point is accurate execution, not merely obtaining information.

### G05 — craft refinement

**Scene:** Hands carefully refine a plain wooden joint or simple material edge using a hand tool; one area visibly shows rough-to-finished improvement within the same object.

**What must be visible:** skilled refinement and quality improvement.

**Avoid:** decorative art, expensive artisan lifestyle cues, dramatic sawdust/action, finished product desirability.

**Nearest-neighbour challenge:**
- vs OPP: no new opening/gain is presented.
- vs EXP: no discovery/unknown is central.

### G06 — repeated practice / calibration

**Scene:** A hand adjusts a simple neutral physical mechanism against a visible non-textual alignment reference, with an earlier imperfect alignment and current precise alignment both physically legible in the scene.

**What must be visible:** controlled improvement through adjustment/practice, not generic tool use.

**Avoid:** numerical scales/text, laboratory prestige, medical equipment, competition/trophy cues.

**Nearest-neighbour challenge:**
- vs CER: knowing the correct setting is not enough; skilled adjustment toward quality must dominate.
- reject if it reads only as “checking a measurement.”

## OPP candidate briefs

Working priority: pursuing an accessible opening or possibility with visible future value/gain.

**OPP is the highest semantic-risk direction in this generation wave.** Physical openness alone repeatedly collapses into AUT or EXP. Each candidate must make the potential value visible without using money, status, luxury or exaggerated positive emotion.

### G07 — accessible useful resource

**Scene:** A neutral storage/work area has one newly accessible open section containing a clearly usable but ordinary resource/tool/material that was previously inaccessible; a hand is positioned to take/use it. Only one meaningful route is presented.

**What must be visible:** the opening provides usable future value, not merely freedom or mystery.

**Avoid:** money, prizes, gifts, branded products, multiple alternatives, dramatic light from an open door.

**Nearest-neighbour challenge:**
- vs AUT: there is not a choice among routes; value comes from gained access.
- vs EXP: the resource is visible, not unknown.

### G08 — available capacity

**Scene:** A simple neutral system/workspace shows a previously full or unavailable capacity with one clearly open usable slot now available, alongside a plain item ready to occupy/use that slot.

**What must be visible:** an actionable capacity/opportunity that can improve the next state.

**Avoid:** calendar/UI, parking/real-estate consumer associations, scarcity marketing, queues or status.

**Nearest-neighbour challenge:**
- vs CER: the open slot is not merely clearer structure.
- vs AUT: there are not multiple choices.
- reject if “opportunity” depends on knowing an external rule.

### G09 — enabled next-stage access

**Scene:** A neutral physical process has one now-open gateway revealing a clearly visible next-stage capability/resource beyond it, with the route already enabled and no alternative paths. The benefit beyond the gateway must be concrete and ordinary, not mysterious.

**What must be visible:** access to a useful next stage rather than exploration of an unknown space.

**Avoid:** corridor/door-only composition, adventure scenery, treasure, sunrise symbolism, celebratory lighting.

**Nearest-neighbour challenge:**
- vs EXP: what is gained is visible, not unknown.
- vs AUT: there is one enabled opportunity, not freedom among alternatives.

**OPP falsification rule:** if blind reviewers describe a candidate equally often as freedom/choice, curiosity/discovery, or generic transition, it fails even if the image is attractive.

## Candidate review gate

Generation is only Stage A. No generated image enters `stimuli-v0.1.json` directly.

For every generated candidate record separately:

1. direct visual description without intended label;
2. one-sentence intended mapping rationale;
3. strongest alternative direction;
4. nearest-neighbour challenge result;
5. semantic status: PASS / AMBIGUOUS / FAIL;
6. visual-confound status: brightness, contrast, complexity, salience, familiarity, valence, people/demographic cues, style;
7. independence from the other exemplar candidate for the same direction.

## Blind semantic check before freeze

Before any generated candidate is promoted to final-set status, run a blind review where the reviewer does not see the internal target code. At minimum, present the eight short direction definitions in neutral order and ask which one or two best fit the visible scene.

A candidate should not pass merely because the intended direction is plausible. The intended direction must be materially more defensible than its nearest neighbours.

This is a design-screening gate, not construct validation.

## Stage B normalization

After semantic selection, the proposed 16-image set must be normalized/audited as a set:

- comparable crop and 1:1 framing;
- no direction systematically brighter/darker, simpler/busier, warmer/cooler or more human/social than another unless unavoidable and explicitly documented;
- avoid one direction being uniquely abstract, uniquely photographic, uniquely indoor/outdoor or uniquely object/people based;
- similar effective subject size at mobile display;
- re-render a passing concept if needed to reduce low-level confounds without changing its semantic scene.

Only after Stage B may selected assets be copied into a PrioLens-owned runtime path and hashed/frozen.

## Current authorization

This contract authorizes **candidate generation for INF, MAS and OPP only**.

It does not authorize:

- final stimulus freeze;
- generation for other directions merely for aesthetic uniformity;
- changing direction definitions to fit outputs;
- implementing psychological scoring from generated-image choices.
