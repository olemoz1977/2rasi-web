# PrioLens observable tradeoff replication blind Stage 1 v0.1

You are reviewing 12 candidate visual A/B concept pairs for a short behavioral choice study.

Do not assume any psychological model, intended construct, hidden label, scoring system or grouping.

Your task is to judge only what is visibly different inside each pair and whether the same kind of local A/B relation recurs across different scenes.

For each pair:
1. State the most important visible/meaningful difference between A and B in one sentence.
2. Name any nuisance asymmetry that could make one side more attractive, useful, active, skilled, consequential, difficult, social, safe, complete or visually salient for reasons unrelated to the core difference.
3. Verdict: CLEAN_LOCAL_CONTRAST / AMBIGUOUS / NUISANCE_DOMINATED / HIDDEN_STORY_REQUIRED.

After all 12 pairs:
4. Group pairs that appear to instantiate the same recurring A/B relation despite using different objects or scene families. Do not force every pair into a group.
5. For each group, describe the recurring relation in your own words. Track polarity: say which side of each pair corresponds to each pole.
6. Does the grouping survive scene/domain changes, or is it better explained by material/domain tropes such as pottery, mechanics, water, cards, careful hands, routing devices or technical work?
7. Identify any pairs that break an otherwise coherent group.
8. Give each recovered recurring relation one status: STRONG_REPLICATION / PARTIAL_REPLICATION / LOCAL_ONLY / NO_REPLICATION.

Do not invent psychological meanings such as personality, motivation, leadership, mastery, certainty, influence, autonomy, protection, connection or opportunity.
