# PrioLens D1/D2 evidence reclassification v0.1

Status: ACTIVE METHODOLOGICAL GUARDRAIL
Date: 2026-08-31

## Why this file exists

The standalone-image architecture recovery does **not** erase the negative evidence produced during INF Gate D1 and MAS Gate D2.

Those gates used a matched/controlled comparison methodology that is no longer the PrioLens product architecture. Therefore they cannot decide how PrioLens trials must be constructed.

However, the central question they tested remains directly relevant:

> Do materially different visible mechanisms converge strongly enough on one broad direction label before that label is revealed?

On current AI concept-review evidence, INF and MAS did not establish that cross-context identity strongly enough.

## What D1/D2 actually falsified or weakened

They weakened this inference:

`different local visual mechanisms -> one stable broad direction -> safe direction score`

Observed collapse patterns:
- INF repeatedly reduced toward external steering / routing / causality / control;
- MAS repeatedly reduced toward precision / fit / refinement / skilled execution.

Therefore broad labels must not be treated as already present in a stimulus merely because the designer intended them.

## What D1/D2 did NOT falsify

They did not prove that:
- PrioLens itself is invalid;
- standalone image choice is invalid;
- every old direction must be deleted;
- local visible semantic families are useless;
- no higher-order structure can ever emerge.

They were AI concept-review evidence, not human construct validation.

## Relationship to the standalone correction

The standalone correction changes the **stimulus architecture**:

`one standalone image = one stimulus`

It does not restore broad-direction scoring by default.

The correct combined interpretation is:

1. design and screen standalone images independently;
2. describe each image first by the concrete visible semantic core;
3. keep old AUT/CER/EXP/MAS/CON/INF/PRO/OPP only as optional legacy hypothesis tags;
4. do not promote a legacy direction until multiple materially different standalone exemplars recover a common semantic core across contexts;
5. only then test whether repeated choices support higher-order aggregation.

## Consequence for Gallery triage

The first Gallery triage (`GALLERY_CANDIDATE_BANK_PASS_v0.1.md`) used language such as "strongest new INF candidate". That is too strong given D1/D2.

Correct language is:
- irrigation gate -> **external system steering / distribution** candidate; legacy hypothesis tag: INF;
- room light switch -> **environmental state change from a local action** candidate; legacy hypothesis tag: INF;
- caliper -> **precision measurement / controlled execution** candidate; legacy hypothesis tag: MAS;
- pottery -> **skilled shaping / controlled execution** candidate; legacy hypothesis tag: MAS.

The legacy tag is not the semantic verdict.

## Decision

Do not generate new assets merely to fill old direction quotas such as "AUT needs 3 more".

First build a lower-level semantic bank from the recovered Gallery and recent assets. Then inspect which families are:
- semantically coherent;
- visually diverse;
- sufficiently distinct from nuisance cues;
- potentially related to one another at a higher level.

Old eight-direction labels remain research hypotheses only.

## Solo-work implication

Because the user is working alone, external human validation is deferred rather than made an immediate blocker.

In the current solo phase:
- ChatGPT performs structured semantic/confound triage;
- independent AI reviews may be used blind as adversarial alternative-reading checks;
- AI agreement is not called validation;
- user self-reading is only a sanity check;
- a compact external human screen comes later when there is a bank worth testing.

## Guardrail

Never use the standalone recovery as a reason to erase negative D1/D2 evidence.

Never use D1/D2 as a reason to reintroduce matched-pair product architecture.

Both findings survive simultaneously:

> **PrioLens stimulus architecture is standalone-image-first. Broad direction aggregation is still unproven.**
