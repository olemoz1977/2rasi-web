## Interpretation

This matrix is for bank construction only.

A clear image is not evidence that the broad direction is valid. D1/D2 negative evidence still stands: later testing must determine whether materially different exemplars really support a useful common direction-level summary.

The active screening question is simple:

> Can a reasonable viewer understand the scene quickly, does the intended candidate idea feel natural, and is there no obvious visual nuisance likely to dominate preference?

Do not require laboratory-style semantic sterility.

## Next generation priority

Start with **CER**, because it currently has the thinnest usable bank and only one provisional anchor.

Do not generate cosmetic checklist variants. Add semantically different everyday scenes expressing clarity, predictability, known state or settled configuration. If a scene needs a long explanation to connect it to CER, reject it before generation.
