## Top methodological strengths

1. Rejects the assumption that “higher = better” and addresses social desirability issues exposed by reverse-item pilots.
2. Semantic-differential logic is appropriate where both poles are genuinely legitimate.
3. Separate “cannot assess” from midpoint is a sound missing-data distinction.
4. Correctly warns that domain averages are not automatically meaningful in bipolar space.
5. Keeps Models A/B/C/D open and requires empirical testing before DISC/PAEI overlays.

## Top methodological risks

1. Forced bipolarity in constructs such as Emotional Regulation, Empathic Attention, Reflective Self-Awareness and Achievement Drive.
2. Midpoint can mix balance, context-dependence, uncertainty, or jointly high poles.
3. Three items per axis are too unstable for interpreting within-axis dispersion as context flexibility.
4. Retaining exactly 15 axes may preserve redundancy or overlap.
5. Radar/wheel displays and future DISC/PAEI layers can imply equivalence or “more = better”.

## Recommended response and scoring model

Hybrid format:
- genuinely bipolar axes: 5- or 7-position semantic-differential with both poles explicitly described;
- unipolar constructs: 1–5 typicality scale, with reverse-key items only if justified;
- separate “depends on context” option from midpoint;
- separate “cannot assess / no relevant experience” as missing;
- internal signed coding such as −2…+2 only for validated bipolar axes;
- ordinal modelling should be preferred over assuming interval-level measurement.

Scoring:
- signed direction for validated bipolar axes;
- dispersion only as research diagnostics, not user-facing construct with 3 items;
- domains treated as organizational groupings until higher-order structure is supported by CFA/ESEM;
- missing never converted to zero;
- start with ordinal methods and polychoric correlations; consider IRT later if justified.

## DISC integration verdict

**Feasible only as qualitative lens initially.**

WorkStyle axes should not be hand-mapped directly to D/i/S/C. Any numeric correspondence should come from empirical projection into a validated interpersonal/circumplex space and be confirmed in hold-out data. Until then, only exploratory correspondence should be shown and it must not be presented as official DiSC.

## PAEI integration verdict

**Feasible only as qualitative / overlapping projections initially.**

PAEI should not be treated as zero-sum. If quantitative mapping is ever attempted, use four independent or overlapping weighted projections and validate the weights empirically. Qualitative correspondence is safer until data exist.

## Visualization recommendation

Classical radar is not recommended for bipolar axes because it implies outward = more/better.

Prefer:
- neutral center/baseline;
- equal visual status for both poles;
- small bipolar bars or signed markers around a wheel rather than a filled polygon;
- explicit pole labels;
- DISC/PAEI only as optional external layers separated from the WorkStyle core.

Bipolarity should be rejected or constrained when:
- opposite-pole item sets correlate weakly or positively;
- opposite poles form separate factors;
- midpoint mostly represents context-dependence or ambiguity;
- one pole is systematically more socially desirable;
- hybrid model fits substantially better;
- the 15-axis structure fails to replicate.
