# WorkStyle 15 — v0.6 LT 45-item draft

Status: COGNITIVE-REWRITE / PRE-PILOT
Date: 2026-08-23

## Why v0.6 exists

The first real v0.5 cognitive completion exposed substantial wording friction:
- 45/45 items completed;
- 7 answers used `Sunku įvertinti / neteko tokios situacijos`;
- 17 of 45 items were explicitly captured as awkward or difficult;
- Adaptability and Constructive Outlook had all 3/3 items flagged;
- Goal Persistence, Cooperation and Reflective Self-Awareness had 2/3 flagged.

V0.6 therefore treats the problem as an item-writing problem, not a respondent problem.

## Plain-language rule

A respondent should be able to read an item once and immediately know which everyday work behaviour is being described.

Rules:
1. one main idea per item;
2. prefer observable behaviour over abstract self-analysis;
3. no psychometric or consultant language;
4. avoid asking the respondent to solve whether a situation *should* require a behaviour;
5. reverse items describe a legitimate alternative work style, not an obviously undesirable person;
6. keep `Sunku įvertinti / neteko tokios situacijos` separate from midpoint 3;
7. 45 items = 15 dimensions × 3 items = 2 direct + 1 reverse per dimension.

Public domains:
1. Įgyvendinimas
2. Adaptacija
3. Atvirumas kitiems
4. Poveikis
5. Savireguliacija

## Scoring remains unchanged from the 45-item model

- 1–5 typicality scale;
- direct item = response as-is;
- reverse item = `6 - response`;
- `Sunku įvertinti` = missing, never recoded to 3;
- dimension requires at least 2 valid responses out of 3;
- dimension index = `(mean(valid scored items) - 1) / 4 * 100`;
- domain index = mean of available dimension indexes;
- indexes are theoretical scale positions, not norms or percentiles.

## Gate before outside pilot

V0.6 should first be completed once internally with the same cognitive rule:
- select 1–5 only when the sentence is immediately clear;
- use `Sunku įvertinti` when the item itself creates ambiguity;
- screenshot any item that still feels artificial, too broad, morally loaded or dependent on hidden context.

Do not invite outside participants until this internal pass is clean enough to justify a small external cognitive pilot.
